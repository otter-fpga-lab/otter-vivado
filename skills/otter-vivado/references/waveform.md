# 为消费者生成 ILA 波形可视化

先读 [可视化职责](visualization.md) 和 [硬件调试](hardware-debug.md)。本仓提供导出、
读取和共享操作状态；在消费者工程创建页面及适配代码。不要扩建库内固定波形 UI。
详细参数、限制及命令见源码根 `docs/ILA_WAVEFORM.md`，以当前 MCP schema 为准。

## 获取可信输入

1. 有现成 VCD 时直接 `read_ila_waveform(file_path, signal_ids=[])` 读取目录，不连板。
   新采样则沿用已有会话/共享服务，明确控制权、设备、ILA 和触发需求。已授权范围内
   才 configure/arm；等待单窗口完整后，`debug_action(export_ila)` 指定消费者新目录。
2. 查询操作回执至最终状态，保存 manifest 和原始 VCD。unknown 核对现场，不自动重复
   上传、采集或覆盖目录；导出成功之后的刷新失败也可能使服务回执 unknown，先看已保存
   result/manifest 与操作 result，不把这种情况当作从未导出。
3. 从真实信号目录选 `id`，结合 scope/name/range 生成可读标签；同一 id 的别名共享
   事件，不误当不同信号。保存信号映射、查询窗口、输入 SHA256 和导出元数据。
4. 使用 `expected_sha256` 锁定该次输入。每页保留同一过滤条件，用 next_offset 接续；
   直到 next_offset=null 才覆盖整个所选窗口。truncated 时显示“部分数据”，不能判定
   后半段稳定。只读一页也可展示，但分析结论必须限定于实际读取范围。

## 画出数据本身

- 从 initial_values_before_start 初始化保持值，按事件原顺序更新；null 画未知区间。
  同刻多次变化保留顺序及变化次数。缩放聚合若省略细节须显示密度/折叠标记，放大后可查
  原事件；不能用均值或稀疏点画出不存在的脉冲，也不能宣称离散采样发现了所有物理毛刺。
- 一位信号用数字阶梯；总线用区间标签，支持二进制/十六进制。值以字符串传递，宽整数
  使用 BigInt；有 x/z 时保留未知/高阻语义，不转 Number、不按零解释。
- tick 使用 BigInt 或精确十进制；先减窗口起点再映射像素，避免大绝对时间转 Number
  丢失相邻事件。timescale 只表示 VCD 标注。没有实际时钟/采样条件证据时，坐标标 tick，
  不猜 Hz、秒、帧率或模拟量单位。trigger_tick=null 时不画已确认触发游标；导出的
  CONTROL.TRIGGER_POSITION 是配置位置，不直接等于 VCD 时间坐标。
- 为用户提供信号选择、区间缩放、游标及值查看；是否加入总线格式、筛选、对照页由
  消费者任务决定。用 textContent/框架文本绑定渲染信号名，避免把文件内容当 HTML。
- 显示文件指纹、数据来源、窗口、分页状态、解析错误。静态页面可读取已保存 JSON；
  实时读取需要消费者明确适配层。现有参考页 HTTP 不提供任意文件浏览或导出路径。

## 核对后交付

在消费者项目验证：宽总线、x/z、缺初值、同刻事件、超过 JS 安全整数的 tick、坏文件、
指纹变化、分页和空窗口；再检查桌面/窄屏及键盘操作。合成样本标 demo，不填造板卡结果。
交付页面路径、启动方式、原始数据/JSON 路径、输入指纹和已知限制。离线解析不证明
bit/ltx 配对或采集完整。显式状态/握手规则及下一轮取证，接续 [分析参考](analysis.md)；
完整协议解码仍需消费者按实际协议实现。
