# 为消费者生成工程控件

此能力教智能体把工程语义映射成控件；页面、描述 JSON、预设、布局和适配代码保存在
消费者工程。库内不新增产品面板。先读 [硬件调试](hardware-debug.md) 与
[可视化职责](visualization.md)，完整字段/公式/接口见源码根 `docs/DEBUG_CONTROLS.md`。

## 从工程发现语义

1. 读取 RTL、寄存器说明、现有用户参数，发现当前目标、VIO 核 UUID、探针位宽/方向。
   不从 `gain`、`mode` 等名字猜单位、有符号性、枚举或有效高低。缺少关键编码信息先做
   只读原始值展示，补齐声明后再开放写入；不要凭常见约定控制真实设备。
2. 为数值显式填写 signed/fractional_bits/scale/offset、unit、min/max/step；为枚举
   填每个 id/label/raw。范围是工程允许值，不默认放开所有位模式。单位是文字与数值换算
   声明，不代表传感器已经校准；输入探针生成只读仪表或文本。
3. 在消费者工程保存 version=1 JSON，调用 `resolve_debug_controls` 验证与预览；工程值
   和宽原始值保持字符串，不经 JavaScript Number 转换。指纹跟着配置版本保存；改单位、
   范围或编码后重新预览，旧页面不可继续用旧配置提交。

## 生成适合任务的交互

- enum 生成选择框、分段选项或明确标注的双态开关；按钮可以选择预先声明的工程值或预设。
  未映射值显示原始码与“未定义”，不要自动选第一项。有效低显示业务文字并保留实际位值。
- number 按范围/精度选文本、步进器或滑杆。滑杆只有在前端可精确维护网格索引时使用；
  超出 Number 安全整数范围用字符串与 BigInt/十进制库，服务端始终再次精确校验。
  输入草稿与实际读回分开，明确单位、范围、步长；拖动不产生连续 JTAG 写入，用户提交时
  只发一次。非法值展示服务返回的原因，不悄悄舍入或限幅。
- 同时展示实际工程值、可展开的原始位值、观察时间、连接/control、操作回执。缓存过期、
  未知读回、UUID 不符、只读探针、busy 和实验占用分别呈现。界面禁用只是反馈，服务校验
  才是执行边界；不能隐藏 unknown 再自动重发。
- 复用同一个 DebugService 与会话生命周期，按 [实验适配](experiment.md#让本地交互实际接入)
  生成消费者服务端适配。人工按钮调用 submit_control(source='manual')，AI 用
  write_debug_control；它们不是旧参考网页已实现的路由。HTTP 线程向所属循环投递，绑定
  固定会话、profile 指纹与 source，校验请求来源和令牌；超时先查询 operation，不重发。
- 一次点击携带当时 revision、profile 指纹和 value；收到 operation_id 只显示执行中，
  待 succeeded 和语义读回核对后更新确认状态。保存原始回执，说明 VIO 读回不等于业务
  应用成功；设计存在 ack 时另外展示 ack 证据。页面重载不发送初始化值。

## 预设与多参数

预设写入顺序由工程决定，先离线展开让人或智能体检查每项工程值、原始值及目标。逐项调用
write_debug_control，等待该项成功再取最新 revision；中途异常停止并保留部分完成状态。
预设不是事务，不承诺同时生效或回滚，不在恢复连接时自动继续/重跑。若要求同时切换，
需要 RTL 提供影子参数与 apply/ack，而不是追加网页延时。

不要用“置 1、延时、置 0”宣称精确周期复位/脉冲；JTAG 与主机时间不确定，需设计内硬件
脉冲器或已说明的握手。活动实验期间禁止旁路改参数；当前实验 write_vio 只支持原始值，
不会解释此语义描述，也不能绕过独占保护。

交付并验证消费者 JSON、页面、适配启动方法：合法边界、负数/定点、宽整数、有效低枚举、
未知读回、描述变化、设备重编程、重复点击、预设部分失败、交回人工、断线与旧页面。
合成数据标 demo；没有实际浏览器/板卡证据时不要宣称现场控件已验收。
